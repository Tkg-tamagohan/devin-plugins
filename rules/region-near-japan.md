# リージョンは日本に近いものを選ぶ

リージョンやロケーションを指定できるリソースを作成または移行するときは、日本からのレイテンシが低くなるよう、日本国内または日本に最も近いリージョンを選ぶ。
利用者は日本にいることを前提とし、サービスの既定値(多くは北米)に任せると日本からのアクセスが遅くなるためである。

## 手順

1. リソースを作成または移行する前に、リージョンを指定する引数や設定項目があるかを確認し、既定値のまま作成しない。
   - 移行では移行先のリージョンにも同じ基準を適用する。
2. 日本国内のリージョン(例: 東京、大阪)があればそれを選び、なければアジア太平洋のリージョンやロケーションヒント(例: Cloudflare D1 の `apac`)を選ぶ。
3. 日本に近いリージョンを選ぶと追加料金が発生する、または料金が上がる場合は選ばずにユーザーに確認し、料金の差を確認できないときもその旨を伝えて確認を求める。
4. 作成または移行の報告には、選んだリージョンと選んだ理由を書く。

## 対象外

- ユーザーや、仕様書、既存の構成がリージョンを明示している場合
  - その指定に従う。
- リージョンを選べない、またはエッジで自動的に分散されるサービス(CDN、Cloudflare Workers の実行場所など)
- 作業対象リポジトリの規約がリージョンを定めている場合
