# ライブラリ利用時はライセンスを確認・遵守する

外部ライブラリやパッケージをプロジェクトに導入・利用するときは、ライセンスを確認し、その条件を遵守する。
ライセンスを確認しないまま依存を追加しない。

## 手順

1. 導入前にライセンスを特定する。パッケージレジストリのメタデータやリポジトリの LICENSE、COPYING、NOTICE などの一次情報で確認する。
2. プロジェクトとの整合を確認する。プロジェクトのライセンス、配布形態、商用利用の有無と両立するかを判断する。GPL、AGPL、SSPL などのコピーレフト系や商用利用を制限するライセンスは、リンクやバンドルの形態によって条件が変わるため特に注意する。
3. ライセンス条件を遵守する。著作権表示やライセンス条文の同梱、NOTICE の維持、ソース開示義務など、要求される義務を満たす。
4. 既存の依存でも、アップグレードでライセンスが変わることがある。バージョンを上げるときはライセンスを再確認する。
5. ライセンスを確認できない、またはプロジェクトと矛盾する可能性がある場合は、導入を進めずユーザーに確認する。

## 対象外

- 言語やランタイムの標準ライブラリの利用
- ライセンス確認済みの依存の通常利用
